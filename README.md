# th06ncprac

一个用于《东方红魔乡：新典》（Touhou Koumakyou: New Classic）的简易练习辅助工具。

本项目的定位很简单：**在 thprac 尚未正式适配《红魔乡：新典》期间，提供一个只包含常用练习功能的临时替代品。**

它并不试图完整复刻 thprac，也不是 thprac 的官方移植或分支。

## 功能

目前支持：

- Practice 开局自定义
  - 分数
  - 残机
  - Bomb
  - Power
- Stage 1–6 Boss 跳转
- 使用游戏原生 `R` 快速重开后自动恢复资源设置
- 自动读取游戏中选择的难度、角色和机体
- 自动连接 `th06nc.exe`

本工具不会修改游戏文件，仅在运行期间读写游戏进程内存。

## 重要提示：成绩与 Replay

**本工具目前不能生成或保存游戏 Replay 文件。使用本工具练习后打出的成绩，可能被游戏、排行榜或社区的成绩审核规则视为非标准成绩而不予承认。**如果你需要提交正式成绩或保留可验证的完整录像，请不要使用本工具修改开局分数、残机、Bomb、Power 或跳转 Boss；请先确认赛事或社区对练习工具的规定。

## 与 thprac 的区别

相较于 thprac 在其支持游戏中的完整练习功能，本工具目前只为《红魔乡：新典》提供少量已验证的 Practice 辅助：设置开局分数与资源、跳转到 Stage 1–6 的 Boss，并在游戏原生快速重开后恢复资源。它目前还缺少：

- 生成、保存或播放 Replay；本工具写入的练习选项也不会随 Replay 保存。
- 跳转到任意道中段落、指定符卡或符卡阶段等细粒度练习入口。
- thprac 的游戏内扩展菜单、快捷功能和其他游戏支持。
- 经正式成绩验证流程确认的兼容性；本工具改变了游戏进程中的分数或状态，不能保证成绩会被接受。

这是一项在 thprac 尚未适配《红魔乡：新典》期间使用的临时过渡工具。项目优先完成少量常用、可针对目标游戏版本验证的练习功能；Replay 需要适配游戏的记录格式和播放流程，并验证修改后的状态能否稳定重现。当前没有完成这项适配，因此不生成 Replay，也不宣称工具能保留或认证成绩。待 thprac 正式支持该游戏后，建议改用 thprac 获取更完整的练习和 Replay 工作流。

见 [Releases](https://github.com/SecretRenko/th06prac/releases) 页面。

| --- | ---: | --- |
| **Lite** | 小于 0.5 MB | 需要自备 .NET 10 Desktop Runtime (x64) |
| **Portable** | 约 171 MB | 自带运行时，无需安装任何东西 |

两种版本都解压到游戏根目录、与 `th06nc.exe` 相邻。Lite 双击包内最外层的 `th06ncprac.exe` 启动；Portable 双击 `Start-Practice.bat` 启动。

## 使用

1. 启动《东方红魔乡：新典》。
2. 运行本工具。
3. 在游戏中进入 `Practice` 并选择需要练习的关卡。
4. 第一次按 `Z` 进入关卡时，会弹出资源设置窗口。
5. 设置分数、残机、Bomb、Power，以及是否直接进入 Boss。
6. 返回游戏并继续，即可按照指定资源开始练习。

之后在暂停菜单使用游戏自带的 `R` 重开时，本工具会自动恢复当前练习设置。

## 当前限制

- 本工具不会生成 Replay，使用本工具修改游戏状态后的成绩可能不被承认；详见上方“重要提示：成绩与 Replay”。
- 暂不支持任意道中节点跳转。
- 暂不支持单独选择 Boss 非符 / 符卡入口。
- Extra 尚未接入。
- Boss 跳转仍属于简单实现，不能保证所有背景、BGM 和前置状态都与正常流程完全一致。
- 工具不按 SHA-256 拒绝游戏版本。当前识别已研究的旧版与 Steam 版两种内存布局；遇到未知布局会停止连接，避免向未经定位的地址写入。Steam 版已由用户确认开局弹窗、Boss 跳转及 R 重开后资源保持正常；其他组合尚未逐一实测。

如果你需要完整的高级练习功能，请优先关注 thprac 后续对《红魔乡：新典》的正式支持。

## 运行环境

- Windows x64
- 《东方红魔乡：新典》
- Lite 版本需要 `.NET 10 Desktop Runtime (x64)`
- Portable 版本包含运行时，无需额外安装 .NET
